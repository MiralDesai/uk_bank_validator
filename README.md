# UK Bank Validator

Fast, dependency free local validation and normalisation of UK account numbers and sort codes.

## Installation

Requires Ruby 3.4 or later.

Add the gem to your bundle:

```ruby
gem "uk_bank_validator"
```

Or install it directly:

```sh
gem install uk_bank_validator
```
